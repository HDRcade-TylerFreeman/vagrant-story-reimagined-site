# VS Reimagined: showcase site

The public page for VS Reimagined, an unofficial PC remaster by Tyler Freeman (HDRcade).
Unofficial, not affiliated with Square Enix.

Plain HTML, CSS and JavaScript with no build step. Screenshots are real captures from the
game, cropped or resized only. No game data is included here.
